# 决策记录 (ADRs)

## ADR-001: 采用 LangGraph 作为工作流引擎

**状态**: 已接受

**背景**: NL2SQL 流程包含多轮澄清、条件路由与有状态记忆，纯链式调用难以表达。

**决策**: 使用 LangGraph StateGraph 编排节点，状态以 TypedDict 表达，便于持久化与回放。

**后果**: 依赖 LangGraph 生态；节点需保持无副作用以方便测试。

---

## ADR-002: SQL 只读白名单校验

**状态**: 已接受

**背景**: 医疗数据敏感，防止提示注入或模型误生成写操作。

**决策**: `SQLValidator` 默认拒绝非 SELECT 与写关键字；生产环境使用数据库只读账号作为第二道防线。

**后果**: 暂不支持 INSERT/UPDATE 类查询场景；如需支持需引入审批流。

---

## ADR-003: 歧义检测独立于 SQL 生成

**状态**: 已接受

**背景**: 直接生成 SQL 再报错会浪费 LLM 调用且用户体验差。

**决策**: 在生成 SQL 前运行 ambiguity 节点，命中歧义先走 clarification，支持多轮追问。

**后果**: 增加一次 LLM/规则调用；后续评测需单独统计澄清触发率。
